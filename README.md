# BharatTube

**Indian Video Platform App like YouTube**

BharatTube is an Android app focused on Indian content - IPL, Bollywood, regional languages, recipes, education (UPSC/JEE), devotional, farming, etc.

## Features
- Trending Indian videos
- Multi-language support (Hindi, Tamil, etc.)
- Low data mode
- UPI payments for creators
- Categories tailored for India
- Firebase backend

## How to run
1. Clone this repo
2. Open in Android Studio
3. Add your own Firebase google-services.json
4. Sync Gradle and run on device.
